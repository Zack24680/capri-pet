CAPRI v2.1.0 — CODEX DESKTOP PET

1. Extract this capri folder into your Codex pets folder, usually
   %USERPROFILE%\.codex\pets on Windows.
   pet.json and spritesheet.webp must stay together inside capri.
2. In Codex desktop, refresh Settings > Pets and choose Capri.
   Use /pet to show her.

Updating: back up the existing folder. To preserve a custom ID/metadata,
ask a local Codex task with access to that folder to apply the supplied
artwork and animation fields while retaining those identity fields.

This revision corrects the pink torso/hips and asymmetric green/pink limbs
across all nine actions and sixteen gaze poses. Each action has 60 distinct
drawings over one second, configured at 60 fps. Gaze pointer mapping and actual
displayed FPS are unverified. This color revision was locally checked;
installation in the owner's desktop app has not been tested.

Requires custom-track Codex desktop support. No application guards are
patched. No account, API key or build step is needed.
