CAPRI v2.0.0 — CODEX DESKTOP PET

1. Extract this capri folder into your Codex pets folder, usually
   %USERPROFILE%\.codex\pets on Windows.
   pet.json and spritesheet.webp must stay together inside capri.
2. In Codex desktop, refresh Settings > Pets and choose Capri.
   Use /pet to show her.

Updating an existing pet: back up its folder first. If you want to preserve
an existing ID or custom metadata, give this package to a local Codex task
with access to that folder and ask it to apply the artwork and animation
fields while keeping those existing identity fields.

Nine actions each contain 60 distinct poses at a configured 60 fps.
The manifest has proper per-state tracks, not the temporary diagnostic tour.
The atlas also preserves sixteen original gaze drawings; pointer mapping is
unverified. Actual displayed cadence depends on the app/device. The owner
accepted the revision after a trial; other client versions may have limits.

This is a custom-track desktop package, not the old single-PNG installation,
the CLI's smaller atlas format or a managed ChatGPT Pets upload. No app guards
are patched. No account, API key, build, HTML player or video is required.

Updates and GIF showcase: https://github.com/Zack24680/capri-pet
Unofficial fan adaptation. Character/franchise rights remain with their owners.
Artwork generated with OpenAI's built-in image generator.
